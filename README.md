Our objective in this project is to develop a lightweight security gap auditor for gap auditors for personal computers. The application will scan any local machine and identify potential security vulnerabilities without modifying or automatically fixing them. It will analyze open ports, USB-related vulnerabilities, and firewall requirements-if a firewall is active, it will also assess its configuration and overall effectiveness. 
The system will evaluate possible local security risks such as unauthorized access to camera and microphone devices, outdated applications, and wherever sensitive data such as location information is being transmitted externally. In short, the project aims to create a functional auditing tool for personal computers.

It features 
- Open port analysis
- USB vulnerability detection
- Firewall configuration assessment
- Camera & microphone permission audit
- Outdated application detection
- External data transmission inspection
